# 法条引用核验（fatiao-check）

模型引用法条时最常出这几类错：编一个不存在的条号；条号对、内容是另一条；引文和原文字句不符；引用已经废止的法律；沿用修订前的旧条号。这些错误读起来都很像真的，一旦写进律师函、起诉状或合同就很难收回。所以这份 skill 只有一条核心规则：**法条以原文为准，不靠记忆**。核对一律跑脚本，脚本拿不到原文的就如实说"未能核验"。

脚本是 `<skill 目录>/scripts/fatiao.py`，只用 Python 标准库。

## 法律文本从哪来

按以下优先级取原文，报告里会写明每部法律用的是哪个来源、哪个版本：

1. **用户导入的官方文本**：用户从国家法律法规数据库（flk.npc.gov.cn）网页上点"下载"得到 docx，用 `import` 导入，最权威。
2. **随 skill 附带的法律库**（`assets/laws/`）：50 多部常用法律的现行文本，加上近年修订过的法律的前两个版本，以及被《民法典》废止的九部旧法。离线可用。
3. **维基文库**（zh.wikisource.org）：通过官方公开 API 获取并缓存到本地。只会发送法律名称，不会发送用户的文稿内容。中国大陆通常访问不了。网络不通或不允许联网时，加 `--offline`（放在子命令前后都可以），或者设环境变量 `FATIAO_OFFLINE=1`。

**不要**去调用国家法律法规数据库网站的内部接口。那些接口没有公开，自动调用可能违反网站规则。用户需要官方文本时，让他自己在网页上下载，再交给你导入。

## 核验一份文稿

```bash
python fatiao.py check --file 文书.txt            # 文字报告
python fatiao.py check --file 文书.txt --json     # 结构化结果，含每条完整原文
python fatiao.py check "根据《劳动合同法》第四十七条……"
python fatiao.py check --file 旧合同.txt --as-of 2019-06-01   # 按文书日期判断当时法律是否已废止
```

脚本能识别的引用写法：`《中华人民共和国劳动合同法》第三十九条第一款第（二）项`、`《民法典》第五百八十五条`、`劳动合同法第82条`、`《刑法》第一百三十三条之一`、`第三十八条、第三十九条和第四十条`、`第五百八十五条至第五百八十七条`、`第三十六、三十八条`，以及接在法律名称后面的"本法第X条""该法第X条"。docx 和 pdf 先转成纯文本再交给脚本。

**报告中各状态的含义和处理方法：**

| 状态 | 含义 | 你要做的 |
|---|---|---|
| ✗ 条文不存在 / 款不存在 / 项不存在 | 这个条号或款项在该法中根本没有 | 用报告给出的"内容最接近的条文"，或者用 `search` 找到正确条号，再用 `show` 核对原文 |
| ✗ 引文与该条原文不符 | 文中引号里的话不在这一条里 | 报告会指出引文实际出自哪一条。把条号改对，引文改成原文 |
| ✗ 疑似引错条号 | 没有引文，但文中描述的内容明显属于另一条 | 用 `show` 看两条原文，确认后改正 |
| ✗ 引用的是修订前的旧版条号 | 文意符合该法某个旧版本的这一条 | 改成现行版的对应条号。如果文书本来就该适用旧法（比如写于修订之前），要说明这一点 |
| ✗ 法律已废止 | 例如《合同法》已于 2021-01-01 被《民法典》取代 | 改引新法的对应条文。脚本会给出相似度最高的候选，务必核对原文；也要注意新法有没有改实质内容，比如诉讼时效由二年改为三年 |
| △ 引文与原文有出入 | 引文大体对，但字句不同 | 照原文逐字改正 |
| ○ 条文存在，请核对文意 | 条号存在，文中没有直接引文，脚本没法自动判断文意 | **由你判断**：用 `--json` 或 `show` 读完整原文，看文中的说法是否准确、有没有夸大、漏掉条件或张冠李戴 |
| ✓ 核对一致 | 引文或表述与原文一致 | 无需修改 |
| ? 未能核验 | 本地没有这部法律，也没能联网获取（常见于地方性法规、部门规章、部分司法解释） | 如实告诉用户这处没有核验，建议他从官方数据库下载文本后用 `import` 导入 |

脚本给出的"最接近的条文""新法对应条文"都是按文字相似度算出来的候选，不是结论，**一定要用 `show` 读原文确认后再采用**。

**版本以施行日期为准。** 脚本按今天（或 `--as-of` 指定的文书日期）选取当时正在施行的版本。已经通过、但还没施行的修正版，比如《商标法》2026 年修正、2027 年 1 月 1 日施行，不会被当成现行版。报告开头会说明用的是哪一版。新近修订的法律（例如《治安管理处罚法》2025 年修订、《仲裁法》2025 年修订、《反不正当竞争法》2025 年修订、《律师法》2026 年修正）条号变化很大，内容也可能有实质修改，比如申请撤销仲裁裁决的期限由六个月改为三个月。这类修订你很可能不知道，所以凡是脚本说"旧版条号"的地方，都要用 `show` 读新条文，看内容有没有变，而不只是改个条号。

## 回复用户的方式

1. 先给结论：共核对几处引用，几处有问题。
2. 每个问题写清楚：原文怎么引的，错在哪，正确的条号和原文是什么（引原文时用脚本输出的文字，不要凭记忆改写），以及建议怎么改。
3. "○ 请核对文意"的条目，要逐条说明你读完原文后的判断，不要只是转述脚本的输出。
4. 注明用的是哪个版本的法律文本，并提醒：转录文本仅供核对，正式提交的文书请以国家法律法规数据库的标准文本为准。
5. 只做引用核对。是否构成违法解除、能赔多少钱这类问题属于法律意见，不在本 skill 的范围内。如果顺带谈到，要说明这是一般性信息，不是法律意见。

## 你自己要引用法条时

写文书、回答"某某情况依据哪条法律"时，先用 `search` 找到条文，再用 `show` 读原文，然后才引用。引文照抄原文，条号用 `show` 显示的那个。文稿写完后再跑一遍 `check`。

```bash
python fatiao.py search 劳动合同法 二倍 工资       # 在一部法律里找同时包含这些关键词的条文
python fatiao.py show 劳动合同法 82                 # 显示第八十二条（含款、项）
python fatiao.py show 民法典 585.2                  # 第五百八十五条第二款
python fatiao.py show 劳动合同法 39.1.3             # 第三十九条第一款第三项
```

## 补充法律

```bash
python fatiao.py fetch 中华人民共和国反垄断法          # 从维基文库获取到本地缓存
python fatiao.py import 下载/中华人民共和国XX法.docx   # 导入用户下载的官方文本（优先使用）
python fatiao.py list                                  # 本地已有哪些法律、哪些版本
```

更多规则见 `references/citation-rules.md`：条、款、项的写法，修正和修订对条号的影响，被《民法典》废止的九部法律，司法解释的名称，以及常见错误。
