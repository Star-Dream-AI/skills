# 诗词格律（shici-gelv）

## 为什么必须用脚本

语言模型是从字形和文本统计里学到平仄的，"听"不到声调，也记不住每个字归哪个韵部。最常见的错误有三种：

- 把入声字当平声。国、白、一、十、竹、读、别这些字普通话读平声，在平水韵里却是仄声。
- 把邻韵当同韵。比如东、冬两韵混押，或者元韵和真、文两韵混押。
- 写完的诗不合律，自己还说"合律"。

所以这份 skill 的核心规则只有一条：**不靠感觉判断平仄和韵部，一律用 `scripts/gelv.py` 查和检查。**脚本负责声调和韵部，你负责字义、语境和诗意。脚本会把它判断不了的地方列出来交给你，主要是多音字该读哪个音、韵书未收录的字。

脚本路径以下写作 `gelv.py`，实际路径是 `<skill 目录>/scripts/gelv.py`。只依赖 Python 标准库，离线运行。

## 选韵书

| 情况 | 用 |
|---|---|
| 用户说"格律诗""近体诗""古诗"、要投传统诗刊，或没说明 | **平水韵**（`--yun pingshui`，默认） |
| 用户说"新韵""普通话""中华新韵"，或明确不想管入声 | **中华新韵**（`--yun xin`，2005 年版十四韵） |

一首诗只能用一种韵书，不能混用。检查报告末尾会附另一种韵书的结论作参考；用户没指定韵书时，把两种结果都告诉他。

## 检查一首诗或对联

```bash
python gelv.py check "白日依山尽，黄河入海流。欲穷千里目，更上一层楼。"
python gelv.py check --file poem.txt --yun xin      # 新韵
python gelv.py check "..." --json                   # 要结构化结果时
```

脚本会自动识别体裁：4 句是绝句，8 句是律诗，更多偶数句是排律，2 句是对联。也可以用 `--form 七律` 指定。只传诗的正文，不要带标题和作者。

**怎么读报告：**

- `✗` **错误**：真的不合律，必须改。比如失粘、失对、孤平、三平尾、出韵、韵脚用了仄声字、第二四六字平仄不对。
- `!` **提示**：重字、韵脚重复、对仗联同位重字、首句平收却不入韵。要提出来，但不一定是错。
- `i` **说明**：合律的变通写法，包括孤平拗救、对句救、特拗（平平仄平仄）、三仄尾、首句借邻韵。告诉用户这些"是允许的"，不要当错误去改。
- **平仄两读字**：脚本按"能读成合律的那个音"计算，并注明这里必须读平还是读仄。你要根据**字义**确认这个读音对不对。比如"浑欲不胜簪"的"胜"是"禁得起"的意思，读平声 shēng，合律；如果是"胜利"的"胜"放在了要求平声的位置，就是错误。常见多音字的义项见 `references/rules.md` 第 6 节。
- **需核实读音的字**：韵书未收录，或者是借异体字、唐代读音、普通话推定出来的。如果它落在关键位置，要向用户说明这是推定。
- **入声字**：报告会单独列出普通话读平、平水韵属仄的字，解释时最好点出来，这是学诗的人最常踩的坑。

**怎么回复用户：**

1. 先给结论：合律 / 不合律（几处问题）/ 合律但有几点要确认。
2. 逐条用大白话解释错误：第几句、第几个字、为什么不行。不要直接把报告整段贴给用户，除非他要看。
3. 给出具体改法，比如换成同义的平声字，或者调换语序。**你提出的每个替换字都先用 `lookup` 查过，改完的整首再跑一遍 `check`**，确认改后合律，并且没有引出新的问题（比如重字、出韵）。
4. 拗救、特拗这类合律的变通写法要明确说"这里没问题"，免得用户误以为是错的。
5. 如果全诗押仄声韵，或者明显是古体诗（如《静夜思》《春晓》），要说明近体格律不适用，不要硬改。

## 写一首格律诗

完整流程和技巧见 `references/writing.md`。要点：

1. 确定体裁、韵书、韵部和起式。用户没说时，替他选一个字多好用的平声韵，并说明选的是哪个。
2. 用 `python gelv.py patterns 七律 --start 仄起 --first-rhyme` 拿到平仄谱，用 `python gelv.py rhymes 阳`（或 `--char 霜`）拿到韵字表，从中先定韵脚。
3. 先求意思通顺、意象具体，再按谱调整用字。
4. **跑 `check`，有任何 `✗` 就改，改完再跑，直到没有错误为止。**两读字按字义逐个确认。律诗的颔联（3、4 句）和颈联（5、6 句）必须对仗，这一点要你自己检查。
5. 交付时附上体裁、韵书、韵部和检查结论。如果某个拗句是有意保留的，要说明理由。

不要在没跑脚本的情况下说"这首诗合律"。脚本跑不了时（比如环境里没有 Python），如实告诉用户格律未经检查，不要靠记忆去保证。

## 对联

`check` 遇到两句等长的文本，就按对联检查：上联末字仄、下联末字平（仄起平落），节奏点平仄相对，上下联同位不能重字。五言、七言的对联还按律句检查孤平、三平尾。**词性和结构是否相对，脚本不检查**，要你自己判断：名词对名词，动词对动词，虚词对虚词，偏正结构对偏正结构，数字、颜色、方位最好各自相对。写春联时还要注意张贴的方向：传统竖排是上联贴右边、下联贴左边。

## 查字、查韵

```bash
python gelv.py lookup 看胜国白          # 平水韵韵部、新韵韵部、普通话读音、常见义项
python gelv.py rhymes 尤                # 平水韵下平十一尤：常用字 / 次常用字
python gelv.py rhymes --char 心         # 查“心”所在的韵部及同韵字
python gelv.py rhymes --yun xin 九文    # 新韵九文的平声字
python gelv.py patterns 五律 --start 平起
```

## 词

词的格律由词牌决定，脚本没有内置词谱。用户要填词时：

- 只用用户提供的词谱，或者能说明出处的可靠词谱（如《钦定词谱》、龙榆生《唐宋词格律》），不要凭记忆写词谱，记错了会误导用户。
- 可以用 `lookup` 逐字核对平仄，用 `rhymes` 找韵字。词韵一般用《词林正韵》，它大致是把平水韵的邻韵合并而成，而且词可以押仄声韵。
- 告诉用户：脚本没有按词谱整体检查过这首词。

## 规则来源与局限

- 规则依据王力《诗词格律》：四种基本句式、粘对、"一三五不论"及其例外（孤平、三平尾）、拗救、特拗。唐诗的实际用法比这套规则宽，详见 `references/rules.md`。
- 平水韵字表来自维基文库《平水韵》，共 106 部、8550 字。部分字借异体字或唐代读音（Unicode Unihan）补足，补足的字在报告中会注明。新韵按普通话读音（pypinyin 数据）计算。数据来源和协议见 `README.md`。
- 脚本不判断诗的好坏、用典对不对、对仗工不工，这些留给你和用户。
