# 写一首合律的诗：流程与技巧

## 流程

1. **定体裁和韵书**。用户说"写首诗"却没说体裁时，绝句最稳妥；要更正式的场合可以写七律。韵书没说就用平水韵，并告诉用户。
2. **选韵部**。字多的平声韵好写，比如东、支、真、先、阳、庚、尤、虞；江、佳、肴、覃、盐、咸字少，难写，叫"险韵"。用户指定了某个韵字（"用'秋'字韵"），就先查出它的韵部：`python gelv.py rhymes --char 秋`。
3. **定起式，拿平仄谱**。运行 `python gelv.py patterns 七绝 --start 平起 --first-rhyme`。七言首句一般入韵，五言首句一般不入韵。
4. **先选韵脚**。从 `rhymes` 列出的常用字里，挑三四个和主题相关、意思不重复的韵字，排好它们在诗中的先后（起、承、转、合）。
5. **按联起草**。先把每联的意思和意象想清楚，再按平仄谱填字：
   - 两字词、三字词按"平平""仄仄"的节奏去组合，比逐个字凑容易得多。
   - 某个词平仄不合，就换同义词、调换语序，或者换个意象，不要硬改成生僻字。
   - 拿不准的字随手查：`python gelv.py lookup 字`。入声字尤其要查。
6. **检查**：`python gelv.py check "整首诗"`。有 `✗` 就针对那个位置修改，然后再检查，直到没有错误。
7. **人工复核**：
   - 两读字：报告说这里须读平（或仄）时，确认字义与之相符。
   - 对仗：律诗的颔联、颈联要词性相对、结构相同，不能合掌。
   - 重字、凑韵、意思是否连贯、有没有落入陈词滥调。
8. **交付**：给出诗，并附一行说明，例如"七言绝句 · 平水韵下平七阳 · 平起首句入韵 · 已用脚本检查，合律"。如果有意保留了拗句，或者用了推定读音的字，要一并说明。

## 改诗时的常用手段

| 问题 | 改法 |
|---|---|
| 某个位置平仄不对 | 换平仄相反的近义字词（如"云"平、"雾"仄，"高"平、"峻"仄，"归"平、"返"仄），或者调换两个词的顺序 |
| 犯孤平（仄平仄仄平） | 把第三字改成平声，构成"仄平平仄平"；或者把第一字改成平声 |
| 三平尾（仄仄平平平） | 把第三字改成仄声 |
| 失粘、失对 | 通常是起式弄错了：重新确认这一句该是平起还是仄起，整句重新组织 |
| 出韵 | 换成同一韵部的字（用 `rhymes` 查），不要换成邻韵的字 |
| 入声字用在了平声位置 | 换成真正的平声字，例如"国"换成"邦"，"白"换成"银" |

## 质量提醒

- 合律只是最低要求，还要写出具体的画面和真情实感，避免空洞的套话。
- 绝句讲究起承转合，第三句往往是转折。律诗中间两联对仗，写景和抒情要有变化。
- 避免整首诗的词语都是同一类（比如四句全是写景）。尾联要收得住，可以留有余味。
- 用户给了题目或场景（祝寿、节日、送别），先把对象和场合的具体细节问清楚或用上，不要写成放之四海而皆准的应酬诗。
